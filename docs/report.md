## 7. Оставшиеся ограничения

По умолчанию частицы являются пробными телами во внешнем поле. Нет backreaction на массивные тела, поглощения, столкновений или релятивистской чёрной дыры. Визуальный радиус иллюстративный. Движущиеся внешние источники требуют согласования обеих фаз общего интегратора; демонстрация использует закреплённый источник. Изменение массы UI извне меняет энергию системы.

Точная взаимная гравитация O(N²) ограничена 4096 частицами. Малый временной шаг снижает ошибку, но не заменяет анализ сходимости для быстрых пролётов. При перегрузке clock отбрасывает backlog, а статистика запаздывает. `Chunk::clear`/`ChunkManager::clear` очищают метаданные; `ComputePipeline::clearChunk` удаляет частицы указанного чанка на GPU с уплотнением. Такая редкая maintenance-операция блокируется на чтении счётчика и требует временных буферов. ID не переиспользуются до перезапуска. После удаления верхняя оценка массы остаётся консервативной и может уменьшать допустимый шаг.

GPU directory ограничен конечным миром и 128 чанками на ось; scan последовательный. Внешние частицы сохраняются в overflow bucket, что может замедлять neighbor queries. Нет GPU spatial hash для бесконечного мира, renderer LOD или сегментации SSBO. Перенос исполняемого файла требует корректного пути к шейдерам. Производительность и фактическая работоспособность на целевом GPU ещё требуют проверки.

## 8. Масштабирование до 10M

Сохранённый формат уже допускает рост до 10M при достаточном per-block SSBO лимите и VRAM. Базовый расход — 60 байт на слот (~600 MB при 10M), дополнительный neighbor-count buffer — 4 байта на слот. Во время resize нужны старые и новые аллокации одновременно. При дефолтных 1000 частицах такой объём не резервируется.

Минимальный GL 4.3 гарантирует SSBO лишь 128 MiB: для таких GPU потребуется сегментация потоков, поскольку split dispatch сам по себе не решает ограничение блока. Для большой плотности нужны profiling и снижение atomic contention; для большого числа чанков — parallel scan и GPU hash; для полной взаимной гравитации — Barnes–Hut/FMM с проверкой ошибок по малому точному эталону. Для отображения 10M нужны замеры fill rate и culling/LOD. Заявление о real-time 10M без этих измерений не делается.
