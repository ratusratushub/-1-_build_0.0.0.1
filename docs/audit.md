# Аудит существующей основы

Прочитаны все исходные C++/GLSL-файлы, заголовки, CMake, тесты и README. Проект первоначально содержал вычислительную демонстрацию, а не 3D-приложение. Ниже перечислены выводы статического аудита и внесённые изменения; они не означают успешную проверку компилятором или GPU.

| Компонент | Наблюдение | Изменение |
|---|---|---|
| CMake | GLFW/GLAD уже закреплены; CPU-тесты всё равно требуют конфигурирования графических зависимостей | Сохранены версии; выделен `space_cpu`, добавлен `SPACE_BUILD_APP=OFF`, отдельный GPU CTest со статусом skip при отсутствии контекста |
| Имена файлов | Несовпадений регистра существующих include/source путей не найдено | Добавлена проверка путей, включая новые файлы |
| EntityManager | Два SoA-потока полезны; ёмкость равна начальному count, дефолт 10M; нет ускорений/принадлежности | Сохранён формат position/mass и velocity; добавлены acceleration/membership/identity, динамический reserve/append, GPU-очистка чанка, seed и конфигурация |
| GPU-аллокация | Исходный лимит SSBO проверяется, но нет увеличения и сохранения данных при неудаче resize | Сохранена проверка лимита; добавлены транзакционное выделение/копирование, проверки ошибок и cleanup частичного создания |
| Пространство | Дефолт 16³ чанков и extent 1000, внешние координаты прижимаются к крайним чанкам | Дефолт 10³ и extent 500; единый boundary contract, отдельный exterior bucket |
| Границы float | Базовая формула может неправильно классифицировать координаты возле нуля из-за cancellation | Коррекция по граням FMA на CPU и GPU; общий GLSL include, regression cases |
| Пространственная структура | Моменты чанков есть, списков частиц и миграции принадлежности нет | GPU histogram/prefix/scatter, актуальные membership/ranges, sparse CPU directory и compaction с постоянными ID |
| Atomic reduction | Четыре float CAS-суммы на частицу, высокая конкуренция и неоднозначный порядок суммирования | В рабочем индексе две uint-атомики на частицу, без расчёта float-моментов |
| Гравитация | Агрегированный far-COM и соседние COM запаздывают, собственная ячейка исключена | Основная модель — точное смягчённое поле внешних тел; optional exact N-body для малых наборов |
| SpatialGrid | COM-расчёт с параллельными диапазонами полезен как экспериментальный компонент | Сохранён отдельно, добавлена валидация моментов; исключён из основной физики |
| Интегратор | Semi-implicit Euler, фиксированный dt без safety contract | Velocity Verlet/KDK, четырёхфазный compute с barriers, ограничение шага и fixed-step controller |
| Массивные тела | CPU Euler и отсутствие закреплённых тел | CPU Verlet, pinned bodies; центральная дыра закреплена; внешние источники расширяемы |
| GPU-синхронизация | Малые fenced snapshots и ограничение очереди полезны | Сохранены принципы; snapshots теперь только статистика, физика не зависит от их возраста |
| CPU snapshot offsets | Запаздывающий CPU range может отличаться от текущего GPU range | Явный `snapshotOffset` только для истории; authoritative ranges находятся в GPU offsets |
| Worker pool | Работает draining shutdown и передача исключений; исключение при постановке диапазонов может оставить незавершённые задачи | Предварительный reserve futures и ожидание поставленных задач даже при ошибке scheduling |
| Main | Скрытое окно 64², выход после 600 шагов; нет управления и рендера | Видимое окно 1440×900, интерактивный цикл, resize/minimize, camera, overlay, CLI |
| Рендер | Отсутствует | GPU vertex stream, depth-tested lattice/axes/sphere, point sprites |
| GL 4.3 portability | SSBO в vertex shader не гарантирован минимальными vertex-stage limits | Частицы читаются как обычный vertex attribute из того же GPU-буфера |
| Статистика | Нет времени GPU | Неблокирующее получение timer-query результата, FPS/clock/camera/chunks/device limit |
| Тесты | Проверяются только pool, COM и симметрия начального движения тел | Расширены CPU invariants, добавлены CPU/GPU reference tests и отдельные Python contract/reference checks |

Обязательное ограничение проверки: сборочные команды в текущей среде недоступны по правилам выполнения. Поэтому ошибки компиляции, линковки, драйвера или интерактивного поведения, которые невозможно установить статическим аудитом, не объявлены исправленными или отсутствующими. Команды полноценной проверки приведены в README.
